# Работа с ZigbeeRubi

- Единственный актуальный источник проекта — `https://github.com/mrWhiskey70/ZigbeeRubi`. Локальные файлы и экспортированные документы являются рабочими копиями или снимками.
- Перед изменениями прочитать `README.md`, `docs/STATUS.md`, согласованный технический проект и актуальный план в `docs/superpowers/`.
- Не начинать архитектуру заново. Цель — автономный ESP32-C6 с локальным фронтом, Zigbee и сценариями; компьютер нужен только для разработки и симуляции.
- Требования пользователя имеют приоритет. Изменения требований фиксировать в спецификации; результаты работ и проверок — в статусе.
- Host и ESP32 должны использовать один переносимый C++ движок. Исполнение правил в браузере не заменяет работу на плате.
- Не считать неизвестное состояние FALSE. Не запускать сценарии первым отчётом после загрузки. Таймеры монотонные; ожидающие действия не восстанавливать после перезагрузки.
- Канал исполнительного устройства идентифицировать отдельно от самого устройства. Не назначать Tuya DP-карту без подтверждённого fingerprint и payloads.
- Сохранять upstream-лицензию, авторство и фиксированный commit. `audit/upstream/` — оригинальные файлы аудита, не каталог новых продуктовых изменений.
- Не выдавать host-тесты за target-сборку или аппаратное подтверждение. Записывать реально выполненные команды и ограничения проверки.
- Не коммитить пароли Wi-Fi, токены, персональные данные, toolchain, временные бинарники и логи с секретами.
