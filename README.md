# ZigbeeRubi

Автономный прототип Zigbee-хаба на ESP32-C6: локальный русский интерфейс, датчики, отдельные каналы, сценарии И/ИЛИ и неблокирующие задержки.

**Единый источник истины:** https://github.com/mrWhiskey70/ZigbeeRubi.

Реализованы общий C++ движок для host/ESP32, симулятор, редактор сценариев, устойчивое хранилище, service API и адресация стандартных Zigbee endpoints. Прошивка **ESP32-C6 /16МБ** и target test harness успешно компилируются на ESP-IDF v5.5.2. **На оборудовании ещё не проверено**; Tuya DP-карта заказанного выключателя неизвестна.

## Начать сейчас

```sh
bash scripts/run_simulator.sh
```

Откройте **http://127.0.0.1:8080**. Виртуальные дверь, PIR и трёхканальный выключатель позволяют проверить сценарии до доставки оборудования. Таймеры работают в C++ процессе, даже когда браузер закрыт.

Лимиты прототипа:16устройств,4канала на устройство,24правила,8триггеров/действий,16узлов условий, глубина4. Первый отчёт после загрузки заполняет UNKNOWN без события. Старые задержки после перезагрузки не восстанавливаются. Команда подтверждается отчётом состояния, а при timeout5с не повторяется.
