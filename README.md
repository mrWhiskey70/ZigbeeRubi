# ZigbeeRubi

Автономный прототип Zigbee-хаба на ESP32-C6: локальный веб-интерфейс, подключение датчиков, управление каналами и сценарии И/ИЛИ с таймерами.

**Единый источник истины:** https://github.com/mrWhiskey70/ZigbeeRubi. Актуальные требования, план, код, результаты проверок и ограничения ведём в этом репозитории. Копии документов вне GitHub — снимки на дату выгрузки.

## Целевой стенд

ESP32-C6 с заявленными 16 МБ Flash, датчик открытия Smartmaxi/Tuya, PIR-датчик Tuya и трёхканальный Zigbee-выключатель без нейтрали. Точный Zigbee fingerprint, endpoints и Tuya datapoints устанавливаются после получения устройств. Три канала нельзя считать подтверждёнными DP1/DP2/DP3 заранее.

Планируемый результат до приезда оборудования: один переносимый C++ движок, host-симулятор и русский веб-интерфейс. Затем — интеграция с Zigbee и проверка на плате. На плате сценарии должны работать без открытого браузера, ПК и облака.

## Воспроизведение текущих тестов

Нужны Python 3 и GCC с поддержкой C++17:

```sh
python3 tools/run_audit_tests.py
```

Бинарные файлы и свежий отчёт создаются в `build/audit/`. Сейчас это тесты Tuya-парсера и двух плагинов, а не тесты ещё не реализованного хаба.
